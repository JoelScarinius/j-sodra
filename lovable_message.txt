Storage URL helper

const STORAGE_PUBLIC_BASE = "https://ytzuftamjgafzgyogpke.supabase.co/storage/v1/object/public";
const STORAGE_BUCKET = "plots";
const STORAGE_PREFIX = "";

const joinUrl = (...parts) =>
  parts
    .filter(Boolean)
    .map((p, i) =>
      i === 0
        ? String(p).replace(/\/+$/g, "")
        : String(p).replace(/^\/+|\/+$/g, "")
    )
    .join("/");

const objectUrl = (key) => joinUrl(STORAGE_PUBLIC_BASE, STORAGE_BUCKET, STORAGE_PREFIX, key);

const fetchJson = async (refOrUrl, bustCache = false, init = {}) => {
  const url = typeof refOrUrl === "string" ? refOrUrl : refOrUrl?.url;
  if (!url) return null;
  const finalUrl = bustCache ? `${url}${url.includes("?") ? "&" : "?"}ts=${Date.now()}` : url;
  const response = await fetch(finalUrl, { cache: "no-store", ...init });
  if (!response.ok) throw new Error(`Failed to fetch ${finalUrl}`);
  return response.json();
};

Refresh model
- There are two different actions and the UI must label them honestly.
- Full refresh:
  - Calls the hosted refresh webhook.
  - Waits for the backend job to finish.
  - Then refetches the published JSON files.
- Reload published data:
  - Only refetches `reports/index.json` and the section JSON files with cache-busting.
  - This does not recompute analytics from Wyscout.

Full refresh behavior
1. Read refresh metadata from `index.refresh`.
2. Start the refresh job with:
   - `POST index.refresh.webhook_url`
   - Fallback to `POST https://ytzuftamjgafzgyogpke.supabase.co/functions/v1/refresh-reports` if the metadata field is missing.
3. If the POST response returns a `run_id`, treat it as a hosted full refresh.
4. Poll the status endpoint every 3 seconds until `status === "succeeded"` or `status === "failed"`.
5. Only after `status === "succeeded"`, refetch `reports/index.json` with a cache-busting query parameter.
6. Then reload the section JSONs from the fresh index.

Hosted refresh failure behavior
- If the webhook is missing, returns 404, returns 500, times out, or returns an error such as missing backend configuration, do not tell me to run a local service.
- Keep the page functional.
- Show a clear UI message such as:
  - "Hosted full refresh is not configured yet. Reloading the latest published reports only."
- Then fall back to published-data reload only.
- Do not block the dashboard just because hosted full refresh is unavailable.

Refresh request example

const REFRESH_FALLBACK_URL = "https://ytzuftamjgafzgyogpke.supabase.co/functions/v1/refresh-reports";
const REFRESH_POLL_INTERVAL_MS = 3000;

const getRefreshUrl = (index) => index?.refresh?.webhook_url || REFRESH_FALLBACK_URL;
const getStatusUrl = (index, runId) => {
  const template = index?.refresh?.status_url_template;
  if (template && runId) return template.replace("{run_id}", encodeURIComponent(runId));
  return `${getRefreshUrl(index)}?run_id=${encodeURIComponent(runId)}`;
};

const FUNCTION_HEADERS = {
  "Content-Type": "application/json",
  Authorization: `Bearer ${SUPABASE_ANON_KEY}`,
  apikey: SUPABASE_ANON_KEY,
};

const reloadPublishedReports = async () => {
  const index = await fetchJson("https://ytzuftamjgafzgyogpke.supabase.co/storage/v1/object/public/plots/reports/index.json", true);
  return index;
};

const startHostedRefresh = async (index) => {
  const refreshUrl = getRefreshUrl(index);
  const response = await fetch(refreshUrl, {
    method: "POST",
    headers: FUNCTION_HEADERS,
    body: JSON.stringify({ force_refresh: true }),
  });

  let started = null;
  try {
    started = await response.json();
  } catch {
    started = null;
  }

  if (!response.ok || !started?.run_id) {
    const details = started?.error || started?.details || `Refresh endpoint failed with ${response.status}`;
    throw new Error(details);
  }

  while (true) {
    const status = await fetchJson(getStatusUrl(index, started.run_id), true, {
      headers: FUNCTION_HEADERS,
    });

    if (status?.status === "succeeded") return status;
    if (status?.status === "failed") {
      throw new Error(status?.stderr_tail?.join("\n") || status?.error || "Refresh failed");
    }

    await new Promise((resolve) => setTimeout(resolve, REFRESH_POLL_INTERVAL_MS));
  }
};

const refreshWithHostedFallback = async (index, onInfoMessage) => {
  try {
    await startHostedRefresh(index);
  } catch (error) {
    onInfoMessage?.("Hosted full refresh is not configured yet. Reloading the latest published reports only.");
  }

  return reloadPublishedReports();
};
